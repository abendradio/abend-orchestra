VCSL English harpsichord: the second harpsichord for abendc --library sonatina

What it is: the "Harpsichord, English" recordings of the Versilian Community Sample Library (VCSL),
by Sam Gossner / Versilian Studios, CC0 (public domain; see LICENSE.txt and VCSL-README.md). Source:
https://github.com/sgossner/VCSL

abendc plays harpsichord parts with the VCSL Flemish harpsichord (../VCSL-Flemish-Harpsichord/). This one is used
instead when you pass  --harpsichord VCSL-English-Harpsichord.sf2 , or automatically if the Flemish folder is missing.

Built with Abend Orchestra's WavToSf2 (src/tools/WavToSf2.cs) from the VCSL recordings.
