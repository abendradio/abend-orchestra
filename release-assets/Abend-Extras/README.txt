Abend-Extras-2.sf2: extra instruments for abendc --library sonatina

Preset 0  pipe organ        instrument: pipe organ        (c2-cis7)  VCSL "Pipe Organ - Loud"
Preset 1  pipe organ pedal  (pedal stops, not used by abendc)          VCSL "Pipe Organ - Loud Pedal"
Preset 2  accordion         instrument: accordion         (g2-c6)    FreePats "Button Accordion HN" (Hohner), tuned preset

Sources and licences (both CC0 1.0, public domain: no restrictions, no credit required):

  Aerophones/Edge-blown Aerophones/Pipe Organ (Loud, Loud Pedal); the organ was sampled by Simon Dalzell of Ivy Audio.
- FreePats, https://freepats.zenvoid.org/Organ/accordion.html ("Button Accordion HN", version 2024-03-29).
Credit given anyway: Versilian Studios (Sam Gossner), Ivy Audio (Simon Dalzell) and the FreePats project.

Every sample in this file is one of those recordings: 21 organ notes, 11 pedal notes and 17 accordion notes, in stereo.
Built with Abend Orchestra's SFZ-to-SF2 converter. Velocity changes the level as for the other instruments; levels are
matched to the default organ and accordion (+15 dB organ, +4 dB pedal, -5.6 dB accordion baked into the samples).
"organ" and "church organ" in a score keep the default General MIDI sound; only "pipe organ" and "accordion" use this file.
