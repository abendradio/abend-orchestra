Libraries built into sndfile.dll (libsndfile 1.2.2, part of FluidSynth's Windows build)

FluidSynth's Windows build links these audio codec libraries into sndfile.dll (found by their version strings in the file).
Abend Orchestra does not use them directly; FluidSynth reads and writes WAV through libsndfile.

  libsndfile 1.2.2         GNU LGPL 2.1 or later         https://github.com/libsndfile/libsndfile
  libFLAC 1.4.2            BSD 3-clause                  https://github.com/xiph/flac
  libogg                   BSD 3-clause                  https://github.com/xiph/ogg
  libvorbis (2020-07-04)   BSD 3-clause                  https://github.com/xiph/vorbis
  libopus 1.4              BSD 3-clause, with patent licences   https://github.com/xiph/opus
  mpg123                   GNU LGPL 2.1                  https://www.mpg123.de
  LAME (libmp3lame)        GNU LGPL (Library GPL) 2      https://lame.sourceforge.io

Each library's own licence file is in the codecs folder next to this file, unchanged, as its project publishes it:

  codecs/flac-COPYING.Xiph   libFLAC, from the 1.4.2 release
  codecs/ogg-COPYING         libogg, from the project's current COPYING
  codecs/vorbis-COPYING      libvorbis, from the project's current COPYING
  codecs/opus-COPYING        libopus, from the 1.4 release
  codecs/mpg123-COPYING      mpg123
  codecs/lame-COPYING        LAME (the GNU Library General Public License, version 2)
  codecs/lame-README         LAME's README, which names its authors and licence

libFLAC, libogg and libvorbis use the same BSD 3-clause terms, naming the Xiph.Org Foundation in the third clause.
libopus uses BSD 3-clause terms whose third clause names the Internet Society, IETF and IETF Trust instead; its full
text, and the royalty-free patent licences that Opus is subject to, are in codecs/opus-COPYING.

The text of the GNU LGPL 2.1 (libsndfile, mpg123) is in the LGPL 2.1 licence file next to this one; the Library GPL 2
(LAME) is in codecs/lame-COPYING.
